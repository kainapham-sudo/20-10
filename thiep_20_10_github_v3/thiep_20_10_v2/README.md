# Thiệp 20/10 gửi Mẹ 🌹

## Chạy thử
Mở `index.html` bằng Chrome. Bấm vào phong thư để xem hiệu ứng.

## Đưa lên GitHub Pages
1. Tạo repository mới tên `thiep-20-10`.
2. Upload `index.html` lên repository.
3. Mở **Settings → Pages**.
4. Ở **Build and deployment**, chọn **Deploy from a branch**.
5. Chọn branch `main`, folder `/(root)`, bấm **Save**.
6. Sau khi xuất bản, link thường có dạng `https://TEN-GITHUB.github.io/thiep-20-10/`.

Thay `TEN-GITHUB` bằng username GitHub của bạn.
